# Vicky's IELTS · 粉色雅思打卡平台

一个纯静态的个人雅思学习记录网站。奶油粉 / 豆沙粉配色，手机和电脑自适应，不需要安装依赖，不需要 API Key 或服务器。

练习内容由你自行刷剑雅完成；网站用于安排、打卡、记录和复盘，不提供自动评分或题库。

## 开始使用

打开 `index.html` 即可查看。长期使用建议部署到 GitHub Pages，并固定在同一个网址、同一个浏览器中使用。直接打开文件与线上网址的记录不互通，可用导出 / 导入迁移。

### 最简单的 GitHub Pages 部署方法

1. 在 GitHub 创建一个新仓库，例如 `vicky-ielts`。个人免费账户可选择 Public。
2. 解压文件包，把 **index.html、style.css、app.js、favicon.svg、README.md** 上传到仓库根目录。不要把外层 `vicky-ielts` 文件夹作为网站入口上传；打开仓库就应当能看到 `index.html`。建议同时保留 `.nojekyll`、`.gitignore`，但网页手动上传看不到隐藏文件时不影响本网站使用。
3. 点击 **Settings → Pages**。
4. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
5. 在 **Branch** 选择 `main`，目录选择 **/(root)**，点击 **Save**。
6. 等待 GitHub 完成构建，回到 Pages 点击 **Visit site**。网址通常是 `https://你的用户名.github.io/vicky-ielts/`。

更新网站时，把改过的文件上传到同一仓库覆盖并提交即可。只要网址保持一致、没有清除浏览器数据，当前浏览器里的学习记录会保留。

GitHub 官方部署说明：https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 每天怎么用

1. 在“任务管理”添加剑雅材料、学习模块、日期、预计用时。也可以在首页生成一项可编辑的参考计划。
2. 想计时时，在首页开始专注。支持暂停、继续、提前结束；切换栏目或刷新后，计时会恢复。
3. 刷完剑雅，在听力 / 阅读 / 写作 / 口语栏目记录材料、实际用时、自填分数和复盘。听力、阅读支持填写答对题数与总题数。
4. **如果这次练习已经用专注计时记录过时间，勾选“本次用时已计入专注计时”**，避免统计重复累加。练习模块的“练习记录用时”仍显示原始练习时长。
5. 完成任务后手动勾选，在首页点击“完成今日打卡”。打卡可以是未在网站逐条记录的线下学习，只需确认当天确实学过。
6. 在日历看安排和过去的复盘，在错题本记错因与订正，在模考栏目安排整套练习与记录四科成绩。
7. 词汇点“记住了”后，按 1 / 3 / 7 / 14 / 30 天安排复习；“还不熟”会放回今天重新复习。同一个词一天最多推进一次熟悉进度。

## 默认目标

- 目标总分 7.5。
- 考试日期暂定 2027-06-30，首页明确标注“暂定”。点击头像或“修改目标”即可调整。
- 每日参考 30 分钟，可在目标设置中修改；专注计时包含忙碌日的 10 分钟选项。
- 日期、打卡和跨日记录均按北京时间（Asia/Shanghai）。
- 连续打卡：今天尚未打卡时，从昨天向前计算；今天已打卡时，从今天向前计算。

## 数据与备份

所有学习数据都保存在当前浏览器的 localStorage 中，不上传到 GitHub，不自动同步到其他设备。公开的是网站代码，不是你存在浏览器中的打卡记录。不要把自己的备份 JSON 上传到公开仓库。

- 顶部“导出备份”下载包含全部记录的 JSON。
- 换设备时先在原设备导出，再在新设备打开同一网站并“导入”。
- 导入会覆盖本机当前记录，操作前有确认提示，也可以先导出当前版本。
- 不要清除该站点的浏览器数据；无痕模式不适合作为长期存储。建议每周导出一次备份。
- 更换域名、浏览器或设备后，需要手动导入。GitHub Pages 本身不提供多设备同步。
- 网站关闭时不弹出专注提醒；重新打开会根据实际时间恢复或结算该轮计时。学习时间以整分钟展示，不足一分钟的专注会累积在底层秒数中。
- 模考均分是四项自填分数按 0.5 取整，仅作记录用途，不代表正式成绩或自动评分。

## 文件说明

| --- | --- |
| index.html | 网站入口 |
| style.css | 粉色主题与响应式布局 |
| app.js | 打卡、任务、计时、记录、备份逻辑 |
